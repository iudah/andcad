4. AI Strategy: Use Public Services First

Scroll inside the panel if the graph is larger than the screen.

Use public AI first.
  • The training cost is zero.
  • The MLOps cost is zero.
  • You can iterate immediately.
  • Public models do these tasks well: netlist generation, log analysis, and tool use.
  • Custom EDA models need labeled data. We do not have this data. Wait until we collect real usage data.
  • Local micro models are only useful for narrow tasks. These tasks must be frequent. They must have low latency limits.
